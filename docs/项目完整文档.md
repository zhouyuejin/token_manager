## 1. 项目概述

### 1.1 产品定位

Token中转平台是一个**API代理/网关服务**，为公司内部提供统一访问大模型API的能力。

### 1.2 核心功能

- 统一API入口，支持多供应商
- API Key管理，按Key限流
- 用量统计与配额管理
- 供应商配额同步（5小时用量、周用量）
- 故障转移与熔断机制

### 1.3 目标用户

| 角色 | 说明 |
|------|------|
| 普通用户 | 内部开发者，调用模型API |
| 管理员 | 管理用户、供应商、配置额度 |

## 4. 数据库设计

### 4.1 核心表结构

#### users - 用户表
```sql
CREATE TABLE `users` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `user_id` VARCHAR(32) NOT NULL COMMENT '业务主键',
  `username` VARCHAR(50) NOT NULL COMMENT '用户名',
  `password` VARCHAR(255) NOT NULL COMMENT '密码(bcrypt)',
  `email` VARCHAR(100) NOT NULL COMMENT '邮箱',
  `role` ENUM('admin','user') NOT NULL DEFAULT 'user' COMMENT '角色',
  `quota` BIGINT NOT NULL DEFAULT 0 COMMENT '总额度',
  `quota_used` BIGINT NOT NULL DEFAULT 0 COMMENT '已使用额度',
  `status` ENUM('active','disabled') NOT NULL DEFAULT 'active' COMMENT '状态',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  `last_login_at` DATETIME DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_users_user_id` (`user_id`),
  UNIQUE KEY `uk_users_username` (`username`),
  UNIQUE KEY `uk_users_email` (`email`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### api_keys - API Key表
```sql
CREATE TABLE `api_keys` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `key_id` VARCHAR(32) NOT NULL,
  `user_id` VARCHAR(32) NOT NULL,
  `api_key` VARCHAR(64) NOT NULL,
  `key_name` VARCHAR(50) NOT NULL,
  `daily_limit` BIGINT NOT NULL DEFAULT 0,
  `daily_used` BIGINT NOT NULL DEFAULT 0,
  `daily_reset_at` DATE DEFAULT NULL,
  `monthly_limit` BIGINT NOT NULL DEFAULT 0,
  `monthly_used` BIGINT NOT NULL DEFAULT 0,
  `monthly_reset_at` DATE DEFAULT NULL,
  `qps_limit` INT NOT NULL DEFAULT 10,
  `ip_whitelist` TEXT,
  `status` ENUM('active','disabled') NOT NULL DEFAULT 'active',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  `last_used_at` DATETIME DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_api_keys_key_id` (`key_id`),
  UNIQUE KEY `uk_api_keys_api_key` (`api_key`),
  KEY `idx_api_keys_user_id` (`user_id`)
```

## 5. API接口设计

### 5.1 接口列表

### 5.2 核心接口示例


```python
class BaseProviderAdapter(ABC):
```

## 9. 快速开始

### 9.1 启动服务

```bash
# 1. 克隆项目
git clone <repo-url>
cd token-manager

# 2. 配置环境变量
cp .env.example .env

# 3. 启动服务
docker-compose up -d

# 4. 查看服务状态
docker-compose ps

# 5. 访问
# API: http://localhost:8000
# 文档: http://localhost:8000/docs
# 监控: http://localhost:3000
```

### 9.2 本地开发

```bash
# 后端
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload

# 前端（待开发）
cd frontend
npm install
npm run dev
```

### 9.3 测试API

```bash
# 登录
curl -X POST http://localhost:8000/api/v1/auth/login \
  -d "username=admin&password=admin123"

  -H "Authorization: Bearer <token>" \
  -d '{"name":"test"}'

# 调用中转API
curl -X POST http://localhost:8000/api/v1/proxy/chat/completions \
```
