# Token中转平台 前端原型设计文档

**版本**：v1.0  
**日期**：2026-08-28  
**技术栈**：React + TypeScript + Ant Design

---

## 1. 设计规范

### 1.1 设计原则

| 原则 | 说明 |
|------|------|
| 一致性 | 统一组件、交互、视觉风格 |
| 简洁性 | 核心功能优先，避免过度设计 |
| 可用性 | 清晰的导航，直观的操作流程 |
| 响应式 | 支持桌面端（推荐1920x1080） |

### 1.2 配色方案

| 用途 | 颜色 | Hex |
|------|------|-----|
| 主色 | 蓝色 | #1677FF |
| 成功 | 绿色 | #52C41A |
| 警告 | 橙色 | #FA8C16 |
| 错误 | 红色 | #FF4D4F |
| 背景 | 浅灰 | #F5F5F5 |
| 文字主色 | 深灰 | #262626 |
| 文字次要 | 中灰 | #8C8C8C |

## 2. 页面原型

### 2.1 登录页面

**路由**：`/login`

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                     ┌─────────────┐                        │
│                     │   Logo      │  Token中转平台        │
│                     └─────────────┘                        │
│                                                             │
│              ┌───────────────────────────┐                 │
│              │  用户名/邮箱               │                 │
│              └───────────────────────────┘                 │
│              ┌───────────────────────────┐                 │
│              │  密码          [显示]      │                 │
│              └───────────────────────────┘                 │
│                                                             │
│              ┌───────────────────────────┐                 │
│              │         登  录            │  ← 主按钮(蓝)     │
│              └───────────────────────────┘                 │

│              还没有账号？ [立即注册]                         │
│                                                             │
```

**组件说明**：
- Logo + 平台名称居中显示

- 底部注册链接

## 3. 组件规范

### 3.1 通用组件

| 组件 | 使用场景 |
|------|---------|
| PageHeader | 页面标题 + 操作按钮 |

| DataCard | 统计卡片 |
| Table | 列表展示 |
| Modal | 弹窗 |
| Form | 表单输入 |
| Drawer | 侧边抽屉 |

| Confirm | 二次确认 |

| 状态 | 颜色 | 图标 |

| 警告 | 橙色 | 感叹号 |
| 错误/失败 | 红色 | 叉号 |
