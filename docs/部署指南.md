## 二、快速启动

### 1. 克隆项目

```bash
git clone <repository-url>
cd token-manager
```

### 2. 配置环境变量

```bash
# 复制环境变量示例文件
cp backend/.env.example backend/.env

# 编辑环境变量
vim backend/.env
```

必须修改的配置项：
- `SECRET_KEY` - JWT密钥，请使用随机字符串
- `MYSQL_PASSWORD` - MySQL密码
- `REDIS_PASSWORD` - Redis密码

### 3. 启动服务

```bash
# 构建并启动所有服务
docker-compose up -d

# 查看服务状态
docker-compose ps
```

### 4. 访问服务

| 服务 | 地址 |
|------|------|
| API | http://localhost:8000 |
| Swagger文档 | http://localhost:8000/docs |
| Prometheus | http://localhost:9090 |
| Grafana | http://localhost:3000 |

## 五、配置供应商

### 方式一：通过管理界面

1. 访问 http://localhost:8000/docs
2. 使用admin账号登录
3. 进入管理后台 → 供应商管理
4. 添加供应商，填写以下信息：
   - 名称：如"火山方舟"
   - 类型：volcengine
   - API端点：如 `https://ark.cn-beijing.volces.com/api/v3`
   - API Key：供应商提供的Key
   - 优先级：数字越小越优先

### 方式二：通过API

```bash
curl -X POST http://localhost:8000/api/v1/admin/providers \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <admin_token>" \
  -d '{
    "name": "火山方舟",
    "type": "volcengine",
    "endpoint": "https://ark.cn-beijing.volces.com/api/v3",
    "api_key": "your-api-key",
    "priority": 10,
    "timeout": 60
  }'
```

## 六、配置模型映射

### 方式一：通过管理界面

1. 进入管理后台 → 模型映射
2. 添加映射，填写：
   - 平台模型ID：如 `gpt-4`
   - 供应商：选择对应供应商
   - 上游模型名：如 `gpt-4`

### 方式二：通过API

```bash
curl -X POST http://localhost:8000/api/v1/admin/models \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <admin_token>" \
  -d '{
    "model_id": "gpt-4",
    "display_name": "GPT-4",
    "provider_id": "prov_openai",
    "provider_model": "gpt-4",
    "status": "active"
  }'
```

## 十、安全建议

1. **修改默认密码** - 首次部署后立即修改admin密码
2. **使用HTTPS** - 生产环境请配置SSL证书
3. **限制API Key** - 为API Key设置日/月限额
4. **IP白名单** - 可为API Key配置IP白名单
5. **定期备份** - 定期备份MySQL数据
