### 阶段一：后端基础接口（核心用户功能）

**目标**：实现用户和API Key的完整功能，让用户可以注册登录并创建使用API Key

#### 1.1 用户接口（/api/v1/users）
- [ ] 实现 `GET /users/me` - 获取当前用户完整信息
- [ ] 实现 `PUT /users/me/password` - 修改密码

#### 1.2 API Key接口（/api/v1/api-keys）
- [ ] 实现 `GET /api-keys` - 获取当前用户的API Key列表
- [ ] 实现 `POST /api-keys` - 创建API Key
- [ ] 实现 `DELETE /api-keys/{key_id}` - 删除API Key
- [ ] 实现 `PUT /api-keys/{key_id}` - 更新API Key
- [ ] 实现 `PUT /api-keys/{key_id}/status` - 启用/禁用API Key

#### 1.3 用量统计接口（/api/v1/stats）
- [ ] 实现 `GET /stats/usage` - 获取用量统计
- [ ] 实现 `GET /stats/usage-by-model` - 按模型统计
- [ ] 实现 `GET /stats/usage-by-day` - 按日期统计

#### 1.4 代理接口基础（/api/v1/proxy）
- [ ] 实现 `GET /proxy/models` - 获取可用模型列表
- [ ] 实现 `GET /proxy/balance` - 获取当前额度

### 阶段三：管理后台接口

#### 3.2 供应商管理（/api/v1/admin/providers）
- [ ] 实现 `GET /admin/providers` - 供应商列表
