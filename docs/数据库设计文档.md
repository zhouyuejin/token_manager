# Token中转平台 数据库设计文档

**版本**：v1.0  
**日期**：2026-08-28

## 1. 数据库概述

### 1.1 技术选型

| 项目 | 选择 |
|------|------|
| 数据库 | MySQL 8.0 |
| 字符集 | utf8mb4 |
| 存储引擎 | InnoDB |
| 事务隔离级别 | RC（读已提交） |

### 1.2 命名规范

| 规则 | 示例 |
|------|------|
| 表名 | 小写字母 + 下划线，s结尾 |
| 字段名 | 小写字母 + 下划线 |
| 索引名 | idx_表名_字段名 |
| 唯一索引 | uk_表名_字段名 |

### 1.3 ER图关系

```
┌──────────────┐       ┌──────────────┐
│    users     │       │   api_keys   │
├──────────────┤       ├──────────────┤
│ pk user_id   │◀──────│ fk user_id   │
│ username     │       │ pk key_id    │
│ password     │       │ api_key      │
│ email        │       │ key_name     │
│ role         │       │ quota_daily  │
│ quota        │       │ quota_month  │
│ status       │       │ fk user_id   │
└──────────────┘       └──────────────┘
                              │
                              │ (记录用量)
                              ▼
                       ┌──────────────┐
                       │ usage_logs   │
                       ├──────────────┤
                       │ pk log_id    │

                       │ fk user_id   │
                       │ model        │
                       │ tokens       │
                       │ latency_ms   │
                       │ status       │
                       └──────────────┘
```

## 2. 数据表设计

### 2.1 用户表 (users)

用户账号信息

| 字段名 | 类型 | 主键 | 自增 | 可空 | 默认值 | 说明 |
|--------|------|------|------|------|--------|------|
| id | BIGINT | ✅ | ✅ | ❌ | - | 主键ID |
| user_id | VARCHAR(32) | ✅ | ❌ | ❌ | - | 业务主键（usr_xxx） |
| username | VARCHAR(50) | ❌ | ❌ | ❌ | - | 用户名，唯一 |
| password | VARCHAR(255) | ❌ | ❌ | ❌ | - | bcrypt加密 |
| email | VARCHAR(100) | ❌ | ❌ | ❌ | - | 邮箱，唯一 |
| role | ENUM('admin','user') | ❌ | ❌ | ❌ | 'user' | 角色 |
| quota | BIGINT | ❌ | ❌ | ❌ | 0 | 总额度（Token数） |
| quota_used | BIGINT | ❌ | ❌ | ❌ | 0 | 已使用额度 |
| status | ENUM('active','disabled') | ❌ | ❌ | ❌ | 'active' | 状态 |
| created_at | DATETIME | ❌ | ❌ | ❌ | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | ❌ | ❌ | ❌ | CURRENT_TIMESTAMP | 更新时间 |
| last_login_at | DATETIME | ❌ | ❌ | ✅ | NULL | 最后登录时间 |

```sql
CREATE TABLE `users` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `user_id` VARCHAR(32) NOT NULL COMMENT '业务主键',
  `username` VARCHAR(50) NOT NULL COMMENT '用户名',
  `password` VARCHAR(255) NOT NULL COMMENT '密码(bcrypt)',
  `email` VARCHAR(100) NOT NULL COMMENT '邮箱',
  `role` ENUM('admin','user') NOT NULL DEFAULT 'user' COMMENT '角色',
  `quota` BIGINT NOT NULL DEFAULT 0 COMMENT '总额度',
  `quota_used` BIGINT NOT NULL DEFAULT 0 COMMENT '已使用额度',
  `status` ENUM('active','disabled') NOT NULL DEFAULT 'active' COMMENT '状态',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `last_login_at` DATETIME DEFAULT NULL COMMENT '最后登录时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_users_user_id` (`user_id`),
  UNIQUE KEY `uk_users_username` (`username`),
  UNIQUE KEY `uk_users_email` (`email`),
  KEY `idx_users_status` (`status`),
  KEY `idx_users_role` (`role`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';
```

CREATE TABLE `api_keys` (

  `monthly_used` BIGINT NOT NULL DEFAULT 0 COMMENT '当月已使用',

  `qps_limit` INT NOT NULL DEFAULT 10 COMMENT 'QPS限制',
  `ip_whitelist` TEXT COMMENT 'IP白名单(JSON数组)',
  `status` ENUM('active','disabled') NOT NULL DEFAULT 'active' COMMENT '状态',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `last_used_at` DATETIME DEFAULT NULL COMMENT '最后使用时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_api_keys_key_id` (`key_id`),

  KEY `idx_api_keys_status` (`status`)

## 3. 索引设计

### 3.1 核心查询索引

| 表名 | 索引名 | 字段 | 类型 | 说明 |
|------|--------|------|------|------|
| users | idx_users_status | status | 普通 | 状态查询 |
| users | idx_users_role | role | 普通 | 角色查询 |
| api_keys | idx_api_keys_user_id | user_id | 普通 | 用户查Key |
| api_keys | idx_api_keys_status | status | 普通 | 状态查询 |
| usage_logs | idx_usage_logs_user_id | user_id | 普通 | 用户用量统计 |
| usage_logs | idx_usage_logs_key_id | key_id | 普通 | Key用量统计 |
| usage_logs | idx_usage_logs_created_at | created_at | 普通 | 时间范围查询 |
| quota_records | idx_quota_records_user_id | user_id | 普通 | 额度记录查询 |
| quota_records | idx_quota_records_created_at | created_at | 普通 | 时间范围查询 |

### 3.2 唯一索引

## 8. 供应商配额相关表（扩展）

### 8.1 供应商配额记录表 (provider_quotas)

记录各供应商的配额同步状态：

```sql
CREATE TABLE `provider_quotas` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `provider_id` VARCHAR(32) NOT NULL COMMENT '供应商ID',
  `quota_type` ENUM('hourly', 'weekly') NOT NULL COMMENT '配额类型',
  `quota_limit` BIGINT NOT NULL DEFAULT 0 COMMENT '配额限制',
  `quota_used` BIGINT NOT NULL DEFAULT 0 COMMENT '已使用量',
  `quota_remain` BIGINT NOT NULL DEFAULT 0 COMMENT '剩余量',
  `quota_percent` DECIMAL(5,2) NOT NULL DEFAULT 0.00 COMMENT '使用百分比',
  `sync_status` ENUM('success', 'failed') NOT NULL DEFAULT 'success' COMMENT '同步状态',
  `sync_error` VARCHAR(500) DEFAULT NULL COMMENT '同步错误信息',
  `sync_at` DATETIME NOT NULL COMMENT '同步时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_provider_quotas` (`provider_id`, `quota_type`),
  KEY `idx_provider_quotas_sync_at` (`sync_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='供应商配额同步记录';
```

### 8.2 供应商API配置表 (provider_api_configs)

记录各供应商的用量查询API配置：

```sql
CREATE TABLE `provider_api_configs` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `provider_id` VARCHAR(32) NOT NULL COMMENT '供应商ID',
  `api_type` ENUM('quota_query', 'balance_query') NOT NULL COMMENT 'API类型',
  `api_url` VARCHAR(255) NOT NULL COMMENT 'API地址',
  `api_method` ENUM('GET', 'POST') NOT NULL DEFAULT 'GET' COMMENT '请求方法',
  `auth_type` ENUM('bearer', 'api_key', 'ak_sk') NOT NULL DEFAULT 'bearer' COMMENT '认证方式',
  `request_template` TEXT COMMENT '请求模板(JSON)',
  `response_mapping` TEXT COMMENT '响应字段映射(JSON)',
  `status` ENUM('active', 'disabled') NOT NULL DEFAULT 'active' COMMENT '状态',
  PRIMARY KEY (`id`),
  KEY `idx_provider_api_configs` (`provider_id`, `api_type`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='供应商API配置';
```
